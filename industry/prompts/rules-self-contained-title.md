【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：项目名 / 招标人 / 采购人 / 中标人 / 机构名。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是编号 / 代号 / 没信息量的 teaser（如 "ZB2026-001"、"公告"、"重磅发布"）时，结合【来源】和正文把主体补进标题。例：原标题 "招标公告" + 来源 "河北交投招标与采购服务平台" + 正文项目名 → "河北交投某高速车路协同设备采购招标公告"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体项目时，用上位词（如"某智慧高速信息化项目"）兜底，绝不凭"行业常识"编一个具体项目名 / 编号 / 数字。
5. 原标题表达的【文章类型和核心动作】是硬边界：变更 / 澄清 / 延期 / 终止 / 中标 / 成交 / 解读这类标题，中文标题必须保留这个类型；不能因为正文谈到一个已经存在的招标项目，就改写成“发布招标 / 推出”。只有原标题明确宣布了招标、采购或意向公开，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的项目、招标人、机构名。
   例：原标题 "某项目中标候选人公示" → "某项目车路云标段中标候选人公示"，不能写成 "某项目发布招标公告"。
   例：原标题 "关于某项目招标文件的澄清公告" + 来源和正文明确是河北交投 → "河北交投某项目招标文件澄清公告"，不能只写成缺主体的 "招标文件澄清公告"。
6. 本条的动作和背景里的旧招标要分清：原文把招标写成过去的事（“此前已发布招标公告”“上周发布的…”），本条是在公布结果、做变更或再次推广时，标题写公布结果、变更或讲解，把招标交代成此前的事；不能写成“发布招标 / 推出”，否则读者会当成今天的新招标。只有原文明确某标段是现在才开放或新增，才对那一项用对应动作。
   例：正文 "上周发布了招标公告 … 现将中标结果公示如下" → "某项目车路云标段中标结果公示"，不能写成 "某项目发布车路云招标公告"。
